# 7. Vista de Despliegue

El Sistema ERP será desplegado bajo una arquitectura cliente-servidor.

Los usuarios accederán al sistema mediante un navegador web utilizando el protocolo HTTPS.

La aplicación estará alojada en un servidor que ejecutará el backend desarrollado con Spring Boot.

El servidor se comunicará con una base de datos PostgreSQL donde se almacenará toda la información del sistema.

Esta arquitectura permite una implementación sencilla, facilita el mantenimiento y ofrece una base sólida para futuras ampliaciones del ERP.
