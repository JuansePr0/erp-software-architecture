# 10. Glosario

## ERP

Sistema de Planificación de Recursos Empresariales que integra los procesos de negocio de una organización.

## Producto

Artículo registrado en el sistema que puede ser adquirido mediante órdenes de compra.

## Proveedor

Persona natural o jurídica encargada de suministrar productos o servicios a la organización.

## Orden de Compra

Documento que registra la solicitud de adquisición de productos a un proveedor.

## Inventario

Conjunto de productos disponibles para el funcionamiento de la empresa.

## API

Interfaz de programación encargada de comunicar el frontend con el backend.

## SPA

Single Page Application. Aplicación web que carga una única página y actualiza dinámicamente su contenido.

## PostgreSQL

Sistema gestor de bases de datos relacional utilizado para almacenar la información del ERP.

## Spring Boot

Framework de Java utilizado para desarrollar el backend del sistema.

## React

Biblioteca de JavaScript utilizada para desarrollar la interfaz de usuario del ERP.
