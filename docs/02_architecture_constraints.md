# 2. Restricciones Arquitectónicas

Para el desarrollo del Sistema ERP se establecieron las siguientes decisiones tecnológicas:

- El backend será desarrollado utilizando Java con Spring Boot.
- El frontend será implementado mediante una Single Page Application (SPA) utilizando React.
- La información será almacenada en una base de datos PostgreSQL.
- La comunicación entre el cliente y el servidor se realizará mediante servicios REST utilizando formato JSON.
- El control de versiones será administrado mediante Git y GitHub.
- Los diagramas UML serán desarrollados utilizando PlantUML.
- La documentación de arquitectura seguirá la metodología arc42.
- Se implementará una arquitectura monolítica debido a que facilita el desarrollo, despliegue y mantenimiento durante las primeras etapas del proyecto.

Estas restricciones permiten mantener una arquitectura sencilla, escalable y adecuada para el alcance definido en este taller.
